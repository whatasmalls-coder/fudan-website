第一步：連接 GitHub

需要一組 GitHub 個人存取權杖（Personal Access Token）才能儲存變更。
取得方式：登入 GitHub → 右上角頭像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token，Repository access 選擇這個網站的倉庫，Permissions 的 Contents 設為 Read and write。
直接前往建立權杖 →
權杖只會暫存在你目前的瀏覽器分頁，關閉分頁後就會消失，不會外流或儲存在任何地方。 若瀏覽器跳出「要儲存這組密碼嗎？」的提示，請選擇「不要儲存」，避免權杖被瀏覽器永久記住。
